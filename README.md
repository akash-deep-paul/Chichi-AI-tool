# Chichi AI Tool

A Python-based voice-controlled desktop assistant built from scratch.

Chichi AI is a desktop voice assistant that helps perform everyday tasks using simple voice commands. It can search YouTube, Google, Wikipedia, provide the latest news, perform calculations, launch applications, and respond using text-to-speech.

The project is built entirely using free Python libraries without relying on paid APIs.

---

# Features

## Voice Assistant
- Push-to-talk voice input (Ctrl + Shift)
- Text-to-speech responses
- Natural voice command recognition

## Web & Search
- Search and play YouTube videos
- Play the next YouTube search result
- Google search
- Wikipedia search
- Weather search
- Price search

## News System
- World news headlines
- India news headlines
- West Bengal news headlines
- Search news by topic
- Read detailed news summaries
- Browse additional related news
- Shows how recently each article was published

## Utilities
- Time
- Date
- Basic calculator
- Open desktop applications
- Open websites
- Close Chrome and Microsoft Edge

# Installation

Install the required Python libraries:

```bash
pip install requests SpeechRecognition sounddevice numpy pyttsx3 keyboard feedparser
```

---

# Run

Open the project folder and run:

```bash
python Chichi.py
```

Hold **Ctrl + Shift** while speaking.
